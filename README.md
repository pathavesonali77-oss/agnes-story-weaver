# Agnes Story Weaver

User will upload this type of recap. Using Agnes api key and Agnes 3.0 flash model write novel with open ending. Make sure write proper novel with proper meaning and engaging story. And give back user complete story txt file.

I give 3 Agnes api keys make sure api 1 write complete in English. Api 2 write in hindi for same recap and api 3 will write in marathi using same recap. Make sure all 3 api keys will works seperately without depend on each other.

Give user 3 separate language novel in 3 separate txt file
